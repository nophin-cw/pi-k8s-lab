# Raspberry Pi K8s + Ansible DevOps Lab

This project automates the deployment of a Kubernetes cluster across 3 Raspberry Pi 5s using K3s, Tailscale, Grafana, and AWX (Ansible Web UI).

## Node Names
- k8s-master
- k8s-worker1
- k8s-worker2

## What's Included:
- Tailscale for secure access
- K3s (lightweight Kubernetes)
- Ansible for automation
- Grafana for monitoring
- AWX for running Ansible with a GUI
